# 🤖 GitHub Copilot Custom Agents

A curated collection of specialized System Instructions for GitHub Copilot. These agents are fine-tuned to provide expert-level assistance for specific frameworks, ensuring cleaner code, better patterns, and fewer hallucinations.

## 🚀 How to Use
1. **Choose your framework** from the list below.
2. **Copy the content** of the markdown file.
3. **Paste it** into your GitHub Copilot "Custom Instructions" or use it to define a custom agent in your IDE.
