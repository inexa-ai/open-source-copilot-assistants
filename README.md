# 🤖 GitHub Copilot Custom Agents

A curated collection of specialized System Instructions for GitHub Copilot. These agents are fine-tuned to provide expert-level assistance for specific frameworks, ensuring cleaner code, better patterns, and fewer hallucinations.

## 🚀 How to Use
1. **Choose your framework** from the list below.
2. **Copy the content** of the markdown file.
3. **Paste it** into your GitHub Copilot "Custom Instructions" or use it to define a custom agent in your IDE.

---

## 📂 Available Agents

| Framework | File | Focus Area |
| :--- | :--- | :--- |
| **React** | [`/agents/react.md`](#) | Hooks, Performance, TypeScript |
| **Next.js** | [`/agents/nextjs.md`](#) | App Router, SSR, Server Actions |
| **FastAPI** | [`/agents/fastapi.md`](#) | Pydantic v2, Async, Dependency Injection |
| **Tailwind CSS** | [`/agents/tailwind.md`](#) | Utility classes, Config, Responsive Design |

> [!TIP]
> Don't see your framework? Feel free to open a PR!

## 🛠️ Contributing
Contributions are welcome! If you have a prompt that significantly improves Copilot's output for a specific tool:
1. Fork the repo.
2. Add your `.md` file to the `agents/` folder.
3. Update the table in this README.
4. Submit a Pull Request.
